# Communication failures

This is the central source-repository location for sanitised session feedback
after repeated requests to explain an answer clearly.

The `wtf` skill owns the trigger and record format. Each session has one file.
The focused retro separates unclear writing from a possible reasoning or scope
failure, proposes one improvement and asks the owner about it.

Incident files must exclude credentials, personal data, private code and whole
transcripts. Recording locally does not authorise committing or publishing them.
No incident is created merely because this policy is being discussed.
