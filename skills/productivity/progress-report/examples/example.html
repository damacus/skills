How scores work

An item earns one point when implemented, published and its local and hosted checks have passed. A check marked “not required” needs evidence explaining why. Partial work earns no point. Deferred work stays in the full-goal count.

Items differ in size. Counts do not estimate effort, time remaining or release readiness. Whole-slice acceptance, merging and deployment are separate states.

First release and the full goal

The first release requires the application runner, sign-in, shared-care recording and a saved-state rollback rehearsal. Offline capture remains in the full goal and is deferred from this release.

Whole-slice acceptance, merging and deployment remain visible in each checklist. Release approval also requires the completed rehearsal and an agreed operating plan.
